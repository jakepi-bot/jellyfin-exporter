Files are written into each profile's output directory following this layout:
<OutputDirectory>/Movies/{Movie Title} ({Year})/{Movie Title} ({Year}).{ext} <OutputDirectory>/TV/{Show Name}/Season {NN}/{NN} - {Episode Name}.{ext}
{NN} is the zero-padded season or episode number (01, 02, ...). Names come from Jellyfin metadata; characters that are not allowed in file names are replaced and duplicate file names are de-duplicated so nothing overwrites an earlier export.
